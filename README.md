# ALA — محطة التحكم في التسكين اللامركزي وإدارة الحشود

تطبيق ويب من صفحة واحدة للتحكم اللحظي في التسكين اللامركزي وإدارة الحشود،
بواجهة عربية داكنة (RTL) بطابع أمني وهندسي.

## المعمارية

- **توجيه مبني على حالة المستخدم** (`role`) يفصل واجهة المشرف المركزي عن واجهة المقاول — دون استخدام عناوين URL.
- **إدارة حالة مركزية** عبر `Context` + `useReducer` تعالج كائنات البيانات: حالة الغرفة، الفئة العمالية، والوردية الزمنية.

## القدرات

- **واجهة المشرف**: خريطة حرارية تفاعلية لكثافة الحشود + مراقب استهلاك طاقة لحظي + مؤشرات أداء.
- **واجهة المقاول**: نموذج إدخال ديناميكي يفرض القيد الهندسي الذي يمنع دمج فئتين عماليتين في نفس المربع السكني.
- **وحدة تحكم إنترنت الأشياء**: مكوّن بصري يتحوّل إلى وضع السكون الطاقي عند تنشيط دالة بدء الوردية الميدانية.
- **وحدة التصاريح الأمنية**: بطاقة رقمية برمز استجابة سريعة يتجدّد كل ٣٠ ثانية، ونافذة منبثقة لإصدار تصاريح مؤقتة مرتبطة بمؤقت تنازلي حقيقي يُعطّل العرض عند الوصول للصفر.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # فحص الأنواع + بناء الإنتاج
npm run preview  # معاينة حزمة الإنتاج
```

التقنيات: React 18 + TypeScript + Vite، مع `qrcode` لتوليد رموز الاستجابة السريعة.
